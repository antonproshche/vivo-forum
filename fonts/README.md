# Шрифты макета

`museo-300.woff`, `museo-500.woff`, `museo-700.woff` и `museo-900.woff` — встроенные подмножества Museo Sans Cyrl из предоставленного `img/design/forum-design.pdf`. Unicode-сопоставление восстановлено из таблиц ToUnicode PDF; шрифты сохранены в WOFF для локального использования. Внешние запросы к сервисам шрифтов не выполняются.

Это подмножества символов исходного макета, а не полные версии семейства. Для расширения контента рекомендуется предоставить полные веб-шрифты с соответствующими правами использования. Для отсутствующих символов предусмотрен системный fallback Arial / sans-serif.
