# Бизнес и образование. Диалог лидеров

Статический сайт областного образовательного форума. Реализация по `img/design/forum-design.pdf`, без фреймворков, сборки и внешних сервисов.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8000`. GitHub Pages обслуживает эти же файлы напрямую. `CNAME` остается `forum.pspion.ru`; конфигурация хостинга не менялась.

## Файлы

- `index.html` — весь контент, семантические разделы, нативный FAQ на `details` / `summary`.
- `styles.css` — оформление по PDF и адаптивные версии.
- `script.js` — мобильная навигация.
- `img/` — исходные изображения, сохраненные с точными именами и регистром.
- `img/optimized/` — WebP-копии тех же фотографий и портретов для быстрой загрузки; исходные пути остаются в `img` как fallback.
- `img/design-details/` — шесть оригинальных декоративных карточек, извлеченных из PDF без текста.
- `fonts/` — локальные подмножества шрифтов из PDF; описание в `fonts/README.md`.

## Ссылки и содержание

Кнопки регистрации открывают [Яндекс Форму](https://forms.yandex.ru/u/6ad07c9f852af3e854c7a1a1/) в новой вкладке. Ссылки организаторов и подвала заданы непосредственно в `index.html`. Раздел FAQ содержит пять согласованных вопросов и ответов. Кнопка скачивания программы убрана; программа остается на странице.

## Проверка

PDF отрендерен целиком в 1920 × 8307 px и просмотрен по частям до начала реализации. Полностраничные скриншоты Chromium сопоставлены с этим нормализованным настольным эталоном. После первого прохода исправлены размеры и положение портретов, интервалы, наложение кругов, композиция фотографий и переполнение адаптивных версий.

Основные размеры проверки: 1920, 1440, 768, 430, 390 и 375 px. Проверяются загрузка изображений, отсутствие ошибок браузера и горизонтального скролла, внешние ссылки, ссылки разделов, телефон и почта, пять FAQ, мобильное меню и клавиатура. Уменьшенная анимация учитывает `prefers-reduced-motion`; FAQ и ссылки разделов доступны без JavaScript.

Публикация, DNS и настройки GitHub Pages в рамках реализации не менялись.
