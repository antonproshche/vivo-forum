# Бизнес и образование. Диалог лидеров

Статический сайт областного образовательного форума. Реализация по `img/design/forum-design.pdf`, без фреймворков, сборки и внешних сервисов.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8000`. GitHub Pages обслуживает эти же файлы напрямую. `CNAME` остается `forum.pspion.ru`; конфигурация хостинга не менялась.

## Файлы

- `index.html` — весь контент, семантические разделы, нативный FAQ на `details` / `summary`.
- `styles.css` — оформление по PDF и адаптивные версии.
- `script.js` — мобильная навигация и уведомления о неподключенных действиях.
- `img/` — исходные изображения, сохраненные с точными именами и регистром.
- `img/optimized/` — WebP-копии тех же фотографий и портретов для быстрой загрузки; исходные пути остаются в `img` как fallback.
- `img/design-details/` — шесть оригинальных декоративных карточек, извлеченных из PDF без текста.
- `fonts/` — локальные подмножества шрифтов из PDF; описание в `fonts/README.md`.

## Данные, которые необходимо предоставить

В начале `script.js` находится объект `integrations`. После получения подтвержденных адресов заполнить соответствующие строки:

```js
const integrations = Object.freeze({
  registration: '', // Подтвержденная ссылка на регистрацию
  program: '',      // Путь к отдельному PDF программы или его URL
  privacy: '',      // Политика обработки персональных данных
  social: ''        // Страница Ассоциации «ПСПиОН» во ВКонтакте
});
```

Скрипт заменит соответствующие кнопки настоящими ссылками и уберет отметки о недостающих адресах. До этого кнопки показывают доступное уведомление, а не имитируют регистрацию или скачивание. Макет `forum-design.pdf` не выдается за программу мероприятия.

Нужны согласованные ответы на все шесть вопросов FAQ. Сейчас в каждом явно указан временный ответ: «Ответ уточняется. Информация будет добавлена после подтверждения организаторами».

1. Кто может принять участие в форуме?
2. Как принять участие в форуме?
3. Смогу ли я попасть на форум без регистрации?
4. Сколько стоит участие в форуме?
5. Сколько секций можно посетить?
6. Предусмотрен ли сертификат об участии?

Сведения о стоимости, сертификатах, порядке допуска и регистрации не добавлялись без источника. Контакты и программа перенесены из PDF. Все предоставленные портреты, логотипы и четыре фотографии найдены; фотографии используются в порядке Photo1–Photo4.

## Проверка

PDF отрендерен целиком в 1920 × 8307 px и просмотрен по частям до начала реализации. Полностраничные скриншоты Chromium сопоставлены с этим нормализованным настольным эталоном. После первого прохода исправлены размеры и положение портретов, интервалы, наложение кругов, композиция фотографий и переполнение адаптивных версий.

Основные размеры проверки: 1920, 1440, 1024, 768 и 375 px. Проверяются загрузка изображений, отсутствие ошибок браузера и горизонтального скролла, ссылки разделов, телефон и почта, шесть FAQ, мобильное меню, клавиатура и модальные уведомления. Уменьшенная анимация учитывает `prefers-reduced-motion`; FAQ и ссылки разделов доступны без JavaScript.

Публикация, DNS и настройки GitHub Pages в рамках реализации не менялись.
